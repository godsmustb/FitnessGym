# Fitness Gym

This is a native Android fitness companion for the Pixel 8, built for personal use and open source (AGPL-3.0). It installs through Obtainium from GitHub Releases. It is a sister app to GuitarNoodle and Coach Québec.

**Status (2026-10-04):** research and planning are done. **Nothing is implemented. The plan is awaiting the owner's approval.**

Read in this order:
1. `docs/RESEARCH.md`: one-page synthesis, including OpenGym, the competitors, the top-10 complaints and the evidence-based defaults
2. `docs/FEATURES.md`: the brainstormed feature list with IDs and priorities (M / V1 / V2)
3. `docs/PLAN.md`: stack, data model, the animation approach, build phases, and the open decisions

Full research sources are in `docs/research/`:
- `01_OPEN_SOURCE.md`
- `02_RESEARCH_PAPERS.md`
- `03_MARKET_AND_COMPLAINTS.md`
